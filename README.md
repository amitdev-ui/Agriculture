# Agricom Website

A modern, responsive agriculture company website built with HTML, CSS, and JavaScript.

## Features

- Fully responsive design
- Reusable navbar component
- Smooth animations and transitions
- Multiple gallery layouts
- Blog section
- Contact forms
- Product showcase

## Setup

This website is ready to be hosted on GitHub Pages.

## Deployment

The website can be deployed directly to GitHub Pages by:
1. Pushing all files to a GitHub repository
2. Enabling GitHub Pages in repository settings
3. Selecting the main branch and root folder

## Files Structure

- `index.html` - Home page
- `navbar.html`, `navbar.css`, `navbar.js` - Reusable navbar component
- `style.min.css` - Main stylesheet
- `animations.css`, `animations.js` - Animation system
- `img/` - All images and assets
- `fonts/` - Font files
